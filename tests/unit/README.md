# Unit tests

This directory contains unit tests, which are written using Catch2. Some basic benchmarks are also included, using Catch2's benchmarking facilities.

## CMake

### Targets

* `libbenbot_tests`: unit test executable for `libbenbot`
* `libchess_tests`: unit test executable for `libchess`

## Dependencies

### C++ libraries
* [Catch2](https://github.com/catchorg/Catch2), unit test framework
